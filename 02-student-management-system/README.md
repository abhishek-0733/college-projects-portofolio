# Student Management System

A web-based Student Management System developed using Python and Django.

This project allows users to manage student information through a simple and user-friendly web interface.

---

## 📌 Project Overview

The Student Management System provides basic CRUD operations for managing student records.

CRUD stands for:

- Create
- Read
- Update
- Delete

The application also includes student search, dashboard statistics, and Django Admin integration.

---

## 🚀 Features

- Student Dashboard
- Add Student
- View Student Details
- Edit Student
- Delete Student
- Search Students
- Student Database Management
- Course Filtering
- Enrollment Date Filtering
- Django Admin Panel
- Responsive User Interface
